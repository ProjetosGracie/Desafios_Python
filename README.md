# 💻 Desafios de Computação em Linguagem C

## 📌 Sobre o projeto

Este repositório reúne **Desafios de Computação desenvolvidos utilizando a linguagem Python**.

Os desafios têm como objetivo colocar em prática conceitos fundamentais de programação, desenvolvendo soluções para diferentes problemas por meio de algoritmos e dos recursos oferecidos pela linguagem Python.

---

## 🎯 Objetivos

Durante o desenvolvimento dos desafios, são trabalhados conceitos como:

* 🧠 Lógica de programação;
* 🔢 Variáveis e tipos de dados;
* 🔀 Estruturas condicionais;
* 🔄 Estruturas de repetição;
* 📋 Listas, tuplas e dicionários;
* 🔤 Manipulação de strings;
* ⚙️ Funções;
* 🏗️ Programação Orientada a Objetos;
* 📁 Manipulação de arquivos;
* 🧩 Estruturas de dados;
* 🔍 Algoritmos de busca e ordenação;
* 📦 Utilização de bibliotecas e módulos.

## ⚙️ Como executar

Para executar os programas, é necessário ter o **Python** instalado.

### 1. Clone o repositório

```bash
git clone URL_DO_REPOSITORIO
```

### 2. Acesse a pasta

```bash
cd Desafios-Python
```

### 3. Execute o programa

```bash
python main.py
```

Em alguns sistemas, pode ser necessário utilizar:

```bash
python3 main.py
```

## 📚 Objetivo acadêmico

Os desafios têm como finalidade desenvolver a capacidade de **resolver problemas utilizando programação**, transformando um problema apresentado em um algoritmo e, posteriormente, em um programa funcional.

A linguagem Python permite desenvolver essas soluções de maneira prática, trabalhando conceitos fundamentais da programação e possibilitando a criação de aplicações de diferentes níveis de complexidade.

## 🚀 Conclusão

Os **Desafios de Computação em Python** proporcionam uma experiência prática de desenvolvimento, permitindo aplicar conceitos de programação na resolução de problemas.

Por meio desses exercícios, é possível desenvolver o **raciocínio lógico**, a capacidade de elaborar algoritmos e a familiaridade com os principais recursos da linguagem Python.
